## 9. Не путать слои

| Слой | Что это | Связь с RAG |
|------|---------|-------------|
| Векторный индекс | поиск и lookup | tools агента |
| Blob / object storage | файлы, манифесты | [не тело индекса / иное] |
| Live-fetch документа задачи | текущий объект запроса | [обычно не индексируется] |
| VFS / scratch агента | эфемерные файлы run | safety-valve, не индекс |
