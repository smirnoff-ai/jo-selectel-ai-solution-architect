# Стиль субтитров и заголовков глав

Всплывашки — часть презентации. Два разных типа с разной ролью:

## 1. Chapter — всплывашка сверху-центра

Используется один раз на смене главы. Большой жирный текст на glass-gradient фоне.

```
┌──────────────────────────────────────────────────┐
│               ┏━━━━━━━━━━━━━━━━━━━━┓             │
│               ┃ 1. Подача заявки ┃                │
│               ┗━━━━━━━━━━━━━━━━━━━━┛             │
│                                                   │
│           [контент интерфейса]                    │
│                                                   │
└──────────────────────────────────────────────────┘
```

- Позиция: `top: 48px; left: 50%; transform: translateX(-50%)`.
- Шрифт: Inter 28px / 700.
- Цвет текста: `#fff`.
- Фон: `linear-gradient(135deg, rgba(16,185,129,0.96), rgba(5,150,105,0.96))` (emerald).
- Скругление: 14px.
- Тень: `0 12px 30px rgba(15,23,42,0.35)`.
- Padding: `14px 28px`.
- Анимация появления: 300 мс (scale 0.92 → 1, opacity 0 → 1).
- Держится: `max(1400ms, ttsDurationOfNextNarrate + 300ms)`.
- Анимация исчезновения: 300 мс fade-out.

## 2. Subtitle — субтитр снизу

Отображается во время каждой реплики (`narrate`). Одна мысль — один субтитр.

```
┌──────────────────────────────────────────────────┐
│                                                   │
│           [контент интерфейса]                    │
│                                                   │
│  ┌─────────────────────────────────────────────┐  │
│  │ Форма заявки проверяется до отправки:       │  │
│  │ ИНН, ОГРН, телефон и почта валидируются.    │  │
│  └─────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────┘
```

- Позиция: `bottom: 44px; left: 50%; transform: translateX(-50%)`.
- Ширина: `min(900px, 86vw)`.
- Шрифт: **Inter 22px / 700** (bold, чтобы обводка смотрелась естественно).
- Цвет текста: `#ffffff`.
- **Обводка букв**: `-webkit-text-stroke: 2px #000000` + `paint-order: stroke fill`. Это главный приём читаемости — буквы всегда чёрно-белые, независимо от фона под плашкой.
- Мягкая тень под буквами: `text-shadow: 0 2px 4px rgba(0,0,0,0.55)` — даёт «воздух» вокруг текста.
- Фон: **`rgba(15,23,42,0.30)`** (30% alpha, БЕЗ `backdrop-filter`). Содержимое страницы реально просвечивает сквозь плашку.
- Граница: `1px solid rgba(255,255,255,0.20)`.
- Скругление: 16px.
- Тень плашки: `0 18px 32px rgba(15,23,42,0.22)`.
- Padding: `18px 28px`.
- Line-height: 1.4.
- Text-align: center.
- Анимация появления: 200 мс (translateY(12px) → 0, opacity 0 → 1).
- Держится: пока не пришёл следующий `narrate` или `hideSubtitle()`.

> **Почему не blur:** `backdrop-filter: blur(...)` делает содержимое под плашкой «молочным» даже при низкой прозрачности — теряется весь смысл просвечивания. Читаемость шрифта обеспечивается не через blur-фон, а через жирную чёрную обводку букв.

## Почему не ffmpeg burn-in

`-vf subtitles=...` через libass:
- Ограниченный набор шрифтов (зависит от системных fontconfig).
- Нет CSS эффектов (backdrop-filter, gradient).
- BorderStyle=3 с непрозрачным box выглядит как блок, а не как glass.
- Невозможно контролировать точный hold time от внешнего events.

DOM-overlay решает всё это, но требует, чтобы оверлеи были частью страницы **во время записи видео**.

## Кастомизация

В 99% случаев ничего не меняйте. Если нужно — правьте `assets/overlay.css`. Ограничения:

- Не опускайте chapter ниже `top: 120px` — может перекрыть хедер приложения.
- Не поднимайте subtitle выше `bottom: 120px` — может перекрыть важный контент.
- Максимальная ширина subtitle — 900px. Длинные тексты всегда лучше разбить на 2 реплики.

## Accessibility

Overlay'и получают `aria-live="polite"` — скрин-ридеры прочитают. Цветовой контраст проверен на WCAG AA.
