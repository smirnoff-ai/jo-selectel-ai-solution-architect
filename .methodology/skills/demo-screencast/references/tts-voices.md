# Голоса edge-tts

edge-tts — это бесплатный Python-пакет, обёртка над облачным Microsoft Edge TTS (использует Neural-голоса). Работает без ключа, требует только исходящего доступа к `speech.platform.bing.com`.

## Установка

```bash
pip3 install --user edge-tts
export PATH="$HOME/.local/bin:$PATH"
edge-tts --list-voices | grep ru-RU
```

## Рекомендуемые русские голоса

| Код | Пол | Характер | Применение |
|---|---|---|---|
| `ru-RU-SvetlanaNeural` | F | Дружелюбный, тёплый | **Default для демо заказчику.** |
| `ru-RU-DmitryNeural` | M | Нейтральный, чуть строгий | Корпоративные обзоры, аналитика. |

## Настройка скорости и pitch

edge-tts принимает `--rate +10%` и `--pitch +0Hz`. Для демо лучше не ускорять — оставить `+0%`.

Если голос звучит слишком медленно в сценах с длинным action, **не ускоряйте озвучку**, а сократите текст реплики или увеличьте action — зритель устанет от быстрого чтения.

## Вокальная пунктуация

edge-tts уважает знаки препинания:
- `,` — короткая пауза.
- `.` `!` `?` — длинная пауза, смена интонации.
- `—` (длинное тире) — небольшая пауза, выделение.
- `—`, `…` добавляют естественность.

Избегайте:
- ALL CAPS — иногда буква за буквой читается.
- Аббревиатур без расшифровки (SQL → «эс-кю-эль»). Для сокращений типа ЗСК / СФМ / УБ Svetlana читает как слова («зсэка», «сэфэм», «убэ») — **это ОК, звучит как живой человек произносит**.

## Кеширование

Движок `scripts/build.mjs` сохраняет mp3 в `outDir/_<name>-tmp/seg_NN.mp3`. Если файл уже есть, он не пересинтезируется. Удалите папку tmp если поменяли текст.
