# Поставляемые skills пакета

Лежат в `.methodology/skills/` рядом с `rules/` и `templates/`. Рантайм агента читает `.agents/skills/` — при установке методологии этот каталог копируется туда.

Сейчас в пакете: [`demo-screencast`](demo-screencast/SKILL.md). Остальные skills из роутера в пакет не входят — их ставят из домашнего каталога или другого проекта, если строка таблицы для стека обязательна.
