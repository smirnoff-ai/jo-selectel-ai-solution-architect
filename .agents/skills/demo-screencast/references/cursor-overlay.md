# DOM-курсор и клик-эффекты

Playwright записывает видео через CDP-screencast и **не включает системный курсор**. Поэтому skill рендерит собственный «фейковый» курсор прямо в странице.

## API (Playwright-уровень)

```js
// Плавное движение курсора к элементу (не кликает).
await moveTo(selector);

// Курсор едет → attention-ring мигает вокруг → ripple → реальный page.click.
await click(selector);

// Курсор едет → attention-ring → реальный page.fill (имитирует ввод).
await fill(selector, text);

// Прокрутка к элементу в видимую область.
await scrollIntoView(selector);
```

Все движения имеют `easing: ease-out`, скорость ≈ 1200 px/сек (маленькие перемещения ≥ 250 мс, большие — дольше).

## Что происходит на экране

1. **moveTo / перед click**: курсор едет к цели плавно (catmull-rom-like через requestAnimationFrame).
2. **attentionRing**: перед реальным кликом вокруг цели 250 мс показывается пульсирующая рамка `2px solid oklch(emerald)` с glow.
3. **ripple**: в момент клика из точки курсора расходится круг-волна, opacity 0.7 → 0 за 400 мс.
4. **press**: курсор на 80 мс чуть уменьшается (`scale(0.92)`) + лёгкая тень — имитация нажатия.

## Не используйте `page.click` / `page.fill` напрямую

```js
// ❌
await page.click('button[type="submit"]');

// ✅
await click('button[type="submit"]');
```

Без обёрток курсор останется в прежней позиции, и зритель не поймёт, куда вы нажали.

Если нужно именно raw-действие (например, клик по координате без цели) — вызывайте `api.page.click(...)`, но в этом случае вы отвечаете за визуализацию сами.

## Позиция курсора по умолчанию

После `goto` курсор скрыт и появляется в центре вьюпорта в момент первого `moveTo`/`click`/`fill`. Скрывается при `unmount` (закрытие браузера).

Если хотите спрятать курсор (например, во время заголовка главы) — `hideCursor()`. Показать обратно — `showCursor()`.

## Рекомендуемые паттерны

- **Перед формой** — сделать `moveTo("input:first-child")` чтобы курсор появился на экране заранее и зритель понимал куда смотреть.
- **Для последовательного заполнения** — `fill(sel, text)` сам двигает курсор к каждому полю. Не надо делать `moveTo` перед каждым.
- **После клика по кнопке submit** — подождите 300-500 мс перед следующим действием, чтобы ripple успел отыграть.

## Attention-ring при скролле

Если элемент не в видимой области, `click` / `fill` сначала скроллит к нему через `page.locator(...).scrollIntoViewIfNeeded()`, и только потом показывает ring. Координаты ring пересчитываются после скролла.
