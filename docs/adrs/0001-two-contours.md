# ADR 0001 — Два контура, мок первым

> **Статус:** ✅ Accepted
> **Дата:** 2026-08-25
> **Область:** продукт Рефлекс

---

## Контекст

Бриф разрешает JSON «рядом с агентом». Мы показываем внедрение рядом с объектом, не справочник внутри промпта.

## Решение

Два сервиса: `mock-severholod` (HTTP справочников и dry-run ITSM) и Рефлекс (UI, агент, Postgres). Сначала поднимаем и тестируем мок, потом пишем Рефлекс.

Не берём: один процесс с JSON в репозитории агента; мок как Python-модуль, который Рефлекс импортирует.

## Последствия

Compose чуть толще. Зато контракт мока можно проверить curl без LLM. Смена настоящей CRM потом — замена базового URL.
