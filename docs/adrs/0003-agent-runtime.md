# ADR 0003 — Рантайм агента

> **Статус:** ✅ Accepted
> **Дата:** 2026-08-25
> **Область:** Рефлекс

---

## Контекст

Нужен один агент с tools. Профиль `agent-platform-v1` не фиксирует каркас. Deep Agents и субагенты дали бы второй `card`.

## Решение

LangChain, один конфиг `reflex-appeal`. Привязку 0 / 1 / N пишет тело поискового тула, не модель. Промпты — файлы в git. Langfuse смотрит трассы, тексты промптов оттуда не правим. Полный `card` через `response_format` не отдаём — короткий финал: исход, причина, вопросы, предупреждения, черновик.

Уточнение реализации (sprint 04): `create_agent` на OpenRouter зависал. Пилот — `ChatOpenAI.bind_tools` и явный цикл до 8 шагов. Чекпоинтера LangGraph нет: карточка и лента в Postgres.

## Последствия

Меньше движущихся частей. Смена модели — base URL и имя в настройках. Нет выбора модели в UI. Возврат к `create_agent` — только если стрим на выбранном шлюзе живой.
