# ADR 0003 — Рантайм агента

> **Статус:** ✅ Accepted
> **Дата:** 2026-08-25
> **Область:** Рефлекс

---

## Контекст

Нужен один агент с tools. Профиль `agent-platform-v1` не фиксирует каркас. Deep Agents и субагенты дали бы второй `card`.

## Решение

LangChain, один конфиг `reflex-appeal`. Поиски только читают. Привязку и исход пишет агент через `update_card` (id только из ответа поиска прогона). Расчёт — отдельный `calculate`, запись результата снова через `update_card`. Промпты — файлы в git. Langfuse смотрит трассы, тексты промптов оттуда не правим. `response_format` нет: последний ход — markdown модели, решение на `card.decision`.

Уточнение (sprint 07): на живом OpenRouter `create_agent` + `astream_events(version="v3")` стримит (первая мысль за секунды). Модель — `ChatOpenRouter`, reasoning `effort`. Чекпоинтера LangGraph нет: карточка и лента в Postgres. `thread_id` только в config трассы.

Уточнение (sprint 08): код не собирает отчёт и не правит исход после прогона. Dry-run ITSM смотрит `card.decision.outcome`.

## Последствия

Один каркас агента, живые дельты мысли и ответа в SSE. Смена модели — имя в настройках. Нет выбора модели в UI. Ручной `run_tool_loop` снят.
