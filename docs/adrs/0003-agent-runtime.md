# ADR 0003 — Рантайм агента

> **Статус:** ✅ Accepted
> **Дата:** 2026-08-25
> **Область:** Рефлекс

---

## Контекст

Нужен один агент с tools. Профиль `agent-platform-v1` не фиксирует каркас. Deep Agents и субагенты дали бы второй `card`.

## Решение

LangChain `create_agent`, один конфиг `reflex-appeal`. Привязку 0 / 1 / N пишет тело поискового тула, не модель. Промпты — файлы в git. Langfuse смотрит трассы, тексты промптов оттуда не правим. Полный `card` через `response_format` не отдаём — короткий финал: исход, причина, вопросы, предупреждения, черновик.

## Последствия

Меньше движущихся частей. Смена модели — base URL и имя в настройках. Нет выбора модели в UI.
