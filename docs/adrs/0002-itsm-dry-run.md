# ADR 0002 — ITSM write только dry-run

> **Статус:** ✅ Accepted
> **Дата:** 2026-08-25
> **Область:** мок СеверХолода

---

## Контекст

Бриф просит create/update в режиме dry-run. Настоящая ITSM флага `dry_run` в каждом запросе не имеет.

## Решение

Режим задаёт конфиг мока `ALLOW_TICKET_MUTATIONS` (по умолчанию `false`). `POST`/`PATCH` всегда гоняют ФЛК. Запись в реестр — только если флаг включён. Рефлекс в payload флаг не кладёт.

## Последствия

В пилоте карточка почти всегда с `persisted: false`. Вердикт `auto_in_prod` — прогноз, не факт записи.
