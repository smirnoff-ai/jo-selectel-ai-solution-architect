# Журнал использования AI

Инструменты: Cursor (агент-разработчик), OpenRouter / Qwen 3.6 как модель разбора, Langfuse (локальный контейнер, трассы опциональны).

## Где AI ускорил

1. Контракт мока и сид по пакету заказчика — меньше ручной сверки полей.
2. Каркас FastAPI / Next и карточка по `card.md` — быстрее, чем писать экраны с нуля.
3. Переписанный system prompt skill'ом harness-construction: action space и «не угадывать».

## Где результат пришлось править

`create_agent` (LangGraph) на OpenRouter зависал ~90 с. Агент-разработчик сначала оставил каркас как в концепте. На живом прогоне зависание подтвердилось: заменили на явный цикл `bind_tools`. Qwen отдавал слоты `patch_facts` JSON-строками — добавили coerce. Короткий S2 без «сегодня/компрессор» модель один раз привязала Москву; полный текст S2 оставляет две площадки, как в сценарии.

Не полагались на «красивый markdown» модели: исход на стол пишет предохранитель по карточке.

На S3 модель пропускала поиск площадок и заявок: две ХУ-17 оставляли объект ambiguous, T-884 не находился. Добор справочников после цикла тулов пишет тот же 0/1/N по mention и адресу в тексте — не «самую вероятную Москву».
