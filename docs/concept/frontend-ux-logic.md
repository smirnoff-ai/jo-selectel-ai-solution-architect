# Frontend UX Logic — Рефлекс

> Визуал — [frontend-design.md](frontend-design.md). Стрим — [generation.md](generation.md).

---

## 1. Глобальные принципы

### Optimistic UI

Не применяем к созданию обращения и реплике: ждём 201/202. Исключение: кнопка «Создать» сразу disabled, чтобы не ушёл второй POST.

### Persistence

| Хранилище | Ключ | Что |
|-----------|------|-----|
| cookie | сессия | логин, httpOnly с backend |
| localStorage | `reflex.theme` | `dark` (default) / `light` |
| sessionStorage | `reflex.return` | `desk` / `journal` + query, куда вести «Назад» |
| in-memory | — | EventSource, disabled кнопок |

Черновик формы не храним. Отмена на форме — уход без черновика.

### Recovery при reload

1. Нет cookie → `/login`. История назад на стол не открывает данные: layout проверяет `/me`.
2. Тема — из `localStorage`, иначе `dark`.
3. `/appeals/{id}` — GET card + messages. Если `run_status=running` — снова SSE.
4. Стол и журнал — просто заново запросить. Счётчики не из storage.

### Гонки

Двойной «Создать» / «Отправить» — disabled до ответа. Смена экрана во время SSE — обрываем EventSource, прогон на сервере живёт.

---

## 2. Навигация

- Клик по строке виджета или журнала → карточка.
- Заголовок виджета → журнал с тем же `status`.
- «Назад» → `sessionStorage.return` или стол.
- Стрим на карточке при уходе не стопаем на сервере.

---

## 3. «Чаты»

Отдельного списка чатов нет. Одно обращение = одна лента. Нового чата до POST обращения не бывает.

| Вопрос | Решение |
|--------|---------|
| Переключение на стол во время stream | SSE рвём, прогон доигрывает |
| Удаление обращения | нет |

---

## 4. Ввод

| Вопрос | Решение |
|--------|---------|
| Send | на карточке — реплика; на форме — Создать |
| Stop | нет |
| Черновик реплики | только в памяти поля; после 202 очистить |
| Режим stream/invoke | нет селектора |
| Обрыв SSE | GET card; если running — SSE снова |

---

## 5. Экраны — поведение

**Вход.** Submit только если оба поля не пустые. 401 — текст на форме.

**Стол.** Поллинга нет. Обновить — reload или повторный заход с карточки. «Идёт разбор» видно, если в `recent` есть `run_status=running`.

**Журнал.** Смена фильтра — новый GET. Сброс — все all.

**Форма.** Валидация канала, текста, даты. Отмена → стол. Успех → `/appeals/{id}` и сразу SSE.

**Карточка.** Пока running — блоки могут быть пустыми. После `card_updated` — перерисовка левой колонки. Реплика disabled пока running.

---

## 6. Ошибки

Нет сети / 5xx на форме — сообщение, поля живы. На карточке `run_error` — баннер, статус не «разобрано». 404 обращения — «нет такого», ссылка на стол.
