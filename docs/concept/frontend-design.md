# Frontend Design — Рефлекс

> Поведение — [frontend-ux-logic.md](frontend-ux-logic.md). Экраны — [functional-spec.md](../requirements/severholod/functional-spec.md).
> Мокапы не используем. Пиксели не эталон.

---

## 0. Статус и принципы

- Стек: Next.js App Router, Tailwind 4, shadcn/ui, Lucide.
- Embeddable-пакета нет.
- Прототип диспетчерской: читаемость карточки важнее «вау».
- Семантические токены, не `bg-zinc-500` в экранах.

---

## 1. Дизайн-язык

Направление: **холодный цех** — светлая рабочая доска склада, не SaaS-фиолетовый лендинг.

- Фон: тёплый бумажный off-white. Панели: белые. Границы: стальной серый.
- Акцент: один ледяной teal (`accent`) — статус «идёт разбор», фокус, первичная кнопка.
- Опасное / согласование: янтарный. Ошибка: красный токен. Успех dry-run: тот же teal, не зелёный неон.
- Шрифт UI: **IBM Plex Sans**. Заголовки экранов: **IBM Plex Serif**. Не Inter.
- Иконки: Lucide, один набор, 20px.
- Радиусы и отступы — из shadcn. Тени слабые или никакие.
- Тема: **тёмная по умолчанию** (холодный цех ночью: фон графит, панели чуть светлее, тот же teal). Светлая — запасной вариант, переключатель в шапке. Токены shadcn `light` / `dark`, не сырые hex в экранах.

---

## 2. Layout

Desktop-first, ширина контента ~1280. Адаптив телефона не делаем (ограничение прототипа).

- Шапка: «Рефлекс», логин, переключатель темы, выход. Слева или сверху: Стол / Журнал.
- Стол: сетка 2×2 виджетов.
- Журнал: таблица на всю ширину, фильтры сверху.
- Карточка: две колонки. Левая — документ (вход, факты, системы, решение, расчёт, результат). Правая — чат и след. На узком экране не обещаем.

Resize колонок не делаем.

---

## 3. Экраны

### Вход

Два поля, одна кнопка. Пусто — текст под полем. Ошибка пары — на месте. Имени клиентов на экране нет.

### Стол

Четыре виджета со счётчиком и 3–5 последними строками: время, канал, отправитель, обрезка текста. Пустой виджет — «нет обращений». Пометка «идёт разбор» на строке. Одна кнопка «Создать обращение».

### Журнал

Таблица: время, канал, отправитель, обрезка, статус, кто создал. Фильтры: статус, канал, период. Пустой фильтр — «нет обращений по фильтру».

### Форма создания

Поля из спеки. Ошибка сервера на форме, текст не пропадает.

### Карточка

Шапка: `R-{id}`, статус, кто создал, вердикт auto/HITL, пометка «идёт разбор».

Блоки слева по спеке: вход (read-only), факты (восемь строк, пустые не прячем), ответы систем, решение, расчёт, результат, след последнего прогона.

Чат справа: мысль/тул сворачиваются после шага; markdown диспетчеру раскрыт. Поле реплики внизу.

Не рисуем: «агент не прав», «отправить клиенту», выбор модели.

---

## 4. Стрим

`card_updated` перерисовывает левую колонку целиком (прототип, не точечный patch DOM). Thought/tool — live expand → auto-collapse. `message_delta` печатается в открытом блоке агента.

---

## 5. Состояния

| Состояние | Как |
|-----------|-----|
| Loading стола/журнала | скелет строк, не спиннер на всю страницу |
| Пусто | короткая фраза |
| Ошибка API | баннер на экране, можно повторить |
| Прогон | шапка «идёт разбор», Send реплики disabled |

a11y: кнопки не div, label у полей, focus-visible.
